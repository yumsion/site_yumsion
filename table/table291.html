进行快速的数据导入(导入前分片，避免太多导入导致失败) 【关闭外键和事务】 执行数据导入命令 ( echo "SET FOREIGN_KEY_CHECKS=0;" echo "SET UNIQUE_CHECKS=0;" echo "SET AUTOCOMMIT=0;" echo "SET sql_log_bin=0;" cat /path/to/huge_backup.sql echo "COMMIT;" echo "SET FOREIGN_KEY_CHECKS=1;" echo "SET UNIQUE_CHECKS=1;" ) | mysql --defaults-file=/tmp/.my.cnf --host=1.1.1.2 --port=3306 --user=root --max-allowed-packet=1G database01 #【注意】sql_log_bin 是一个会话级别的系统变量，不要在主库上执行此操作，否则恢复的数据变更不会被同步到任何从库，会导致主从数据不一致。 原理说明： FOREIGN_KEY_CHECKS=0：暂停外键约束检查。 UNIQUE_CHECKS=0：暂停唯一索引检查（导入完成后再统一构建）。 AUTOCOMMIT=0：关闭自动提交，避免每行 INSERT 产生一次磁盘写日志。 sql_log_bin=0：关闭 Binlog 日志记录（不写入二进制日志，大幅减少磁盘 I/O）。 临时调整 MySQL 服务端参数（全局提速） -- 关闭每笔事务实时刷盘（从 1 改为 2，I/O 性能提升极明显） SET GLOBAL innodb_flush_log_at_trx_commit = 2; -- 放大单次数据包限制，防止超大 INSERT 报 Packet error SET GLOBAL max_allowed_packet = 1073741824; -- 1GB
mysql restore
mysql_import.sh #大文件sql数据导入，逐步导入，避免过多数据导入失败。需要SESSION ADMIN权限来关闭bin log，以加快导入速度。 #!/bin/bash

set -o pipefail
export LC_TIME=POSIX

# 参数配置
MYSQL_BIN_FILE='/usr/bin/mysql'
MYSQL_CNF="/etc/my.cnf"
MYSQL_HOST="1.1.1.2"
MYSQL_PORT="3306"
MYSQL_USER="user01"
MYSQL_PASSWORD="password01"
TARGET_DB="db01"
SQL_FILE="sql01.sql"
BATCH_SIZE=10000

# 检查 SQL 文件是否存在
if [ ! -f "$SQL_FILE" ]; then
echo "[ERROR] 错误: 文件 $SQL_FILE 不存在！"
exit 1
fi

echo "[INFO] SQL_FILE $SQL_FILE 存在。"

exec {FD_SQL}<"$SQL_FILE"
[[ $? -ne 0 ]] && echo "[ERROR] $SQL_FILE FAILED, exit..." && exit 1

echo "[INFO] SQL_FILE 文件已打开，准备开始读取。"
TOTAL_COUNTER=0

while true
do
echo "$(date) TOTAL_COUNTER : $TOTAL_COUNTER" >&2

#以下内容会输送到MYSQL中，不要再STDOUT中输出非必要内容
(
# 1. 连接初期设置（关闭约束与日志以提高写入性能）
echo "SET FOREIGN_KEY_CHECKS=0;"
echo "SET UNIQUE_CHECKS=0;"
echo "SET AUTOCOMMIT=0;"
echo "SET sql_log_bin=0;"
echo "BEGIN;"

# 2. 使用 read 逐行读取 SQL 并按批次 COMMIT/BEGIN
count=0
while IFS= read -u "$FD_SQL" -r line || [ -n "$line" ]; do

if [ $count -eq 0 ]; then
echo "BEGIN;"
echo "$line"
echo "[INFO] 第一行$line" >&2
elif [ $count -ge $BATCH_SIZE ]; then
echo "$line"
echo "[INFO] 最后一行$line" >&2
break;
else
echo "$line"
fi
((count++))
done

# 3. 循环结束后提交剩余未提交的数据并恢复设置
echo "COMMIT;"
echo "SET FOREIGN_KEY_CHECKS=1;"
echo "SET UNIQUE_CHECKS=1;"

) | mysql --defaults-file="$MYSQL_CNF" \
--host="$MYSQL_HOST" \
--port="$MYSQL_PORT" \
--user="$MYSQL_USER" \
--password="password01" \
--max-allowed-packet=1G \
--line-numbers \
--skip-ssl \
--unbuffered \
"$TARGET_DB"

# 获取管道中 mysql 命令的返回状态码
if [[ ${PIPESTATUS[1]} -eq 0 ]]; then
echo "数据导入成功完成！"
else
echo "导入过程中发生错误，请检查日志！"
break;
fi
sleep 1 || break
((TOTAL_COUNTER++))
done

exec {FD_SQL}>&-
echo "[INFO] SQL_FILE $SQL_FILE 已经关闭($?)。"
mysql restore
mysql install and init #初始化并创建数据库 mysqld --no-defaults --initialize-insecure --user=yum --datadir=/mnt/mysql_data --log-error=/mnt/mysql_log/error.log #报错与处理 #报错:mysqld: Can't create directory '/mnt/mysql_data/' (OS errno 13 - Permission denied) #Ubuntu 默认会预装 AppArmor，但可能缺少 apparmor-utils 工具包（包含 aa-disable、aa-status 等命令） #安装apparmor管理工具 apt install -y apparmor-utils #配置apparmor权限 查看AppArmor状态（确认mysql规则是否启用） aa-status | grep mysql /usr/sbin/mysqld #临时关闭mysql的AppArmor规则（重启后失效，适合调试） aa-disable /etc/apparmor.d/usr.sbin.mysqld 或 apparmor_parser -R /etc/apparmor.d/usr.sbin.mysqld 或 给 AppArmor 授权 /mnt 目录 # 编辑MySQL的AppArmor规则文件 sudo vim /etc/apparmor.d/usr.sbin.mysqld # 找到以下默认数据目录规则段： # /var/lib/mysql/ r, # /var/lib/mysql/** rwk, # 在其下方添加你的自定义目录权限（关键）： /mnt/mysql_data/ r, /mnt/mysql_data/** rwk, /mnt/mysql_log/ r, /mnt/mysql_log/** rwk, # 保存后重新加载AppArmor规则 apparmor_parser -r /etc/apparmor.d/usr.sbin.mysqld #重新初始化 mysqld --no-defaults --initialize-insecure --user=yum --datadir=/mnt/mysql_data --log-error=/mnt/mysql_log/error.log 注意: --user=yum 的具体作用：指定 mysqld 进程在 Linux 系统中以 yum 用户的身份运行（进程所属用户是 yum），所有 MySQL 数据文件（/mnt/mysql_data 下的文件）的所有者也会是 yum 用户。 数据库的内部管理员用户依然是root #运行 #直接运行 mysqld --no-defaults --user=yum --datadir=/mnt/mysql_data --log-error=/mnt/mysql_log/error.log --socket=/mnt/mysql_data/mysql.sock 或 看实时输出 mysqld --no-defaults --user=yum --datadir=/mnt/mysql_data --log-error=/mnt/mysql_log/error.log --socket=/mnt/mysql_data/mysql.sock --console #登录 mysql -u root --socket=/mnt/mysql_data/mysql.sock #配置登录区域和密码 alter user 'root'@'localhost' identified by "password01"; 或 -- 给 root@127.0.0.1 设置密码（和 localhost 保持一致） ALTER USER 'root'@'127.0.0.1' IDENTIFIED BY 'password01'; -- （可选）如果需要远程连接，还可以设置 root@%（所有IP） -- ALTER USER 'root'@'%' IDENTIFIED BY 'password01'; -- 数据库授权管理 -- GRANT ALL ON ekp20220510.* TO 'root'@'127.0.0.1';
