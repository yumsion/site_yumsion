[WX2560X_B1F1-wlan-ap-APNAME01-radio-2]type ?
dot11a 802.11a #仅支持 5GHz，采用 OFDM 技术，最高速率 54 Mbps。这是最基础的模式，主要用于兼容极老的设备。
dot11ac 802.11ac #WIFI 4 引入了 MIMO（多天线）和 40MHz 信道绑定，速率大幅提升，最高可达 600 Mbps（需终端支持）。这是 5GHz 频段上实现高速连接的基础模式。
dot11an 802.11n(5GHz) #WIFI 5 仅支持 5GHz，引入更宽的信道（最高160MHz）、更高阶调制（256-QAM）和下行 MU-MIMO，速率可达 Gbps 级别。它专注于 5GHz 频段的性能提升。
dot11ax 802.11ax #WIFI 6 同时支持 2.4/5GHz，核心是提升多设备并发效率。引入 OFDMA（正交频分多址）和完整的上下行 MU-MIMO，虽然峰值速率更高（9.6 Gbps），但实际优势在于高密度场景下的稳定性和低延迟。

dot11gn 802.11n(2.4GHz) #WIFI 6 这是 H3C 对 Wi-Fi 6 在 2.4GHz 频段的命名。核心优势不在于单设备峰值速率，而在于通过 OFDMA 等技术，提升多设备并发时的效率和稳定性。

H3C AP 命令
AC控制器 许可备份 AC冗余方案。H3C主流的做法是双链路备份（即1+1热备） 备份AC不需要再单独买一套同样数量的授权。H3C支持License共享，一份授权可以在两台互为备份的AC之间同步使用，不需要叠加购买。 两台AC均支持双链路备份（WX2500H及以上主流型号基本都支持）。 确认型号支持，H3C 的 License 共享机制并不是让一份授权永久地在两台 AC 上同时生效，它的核心是一个30 天宽限期 在主AC上指定备份AC的IP，配置优先级、备份VLAN等参数。 N+1 双链路备份 + License 共享，在备份AC上做对称配置，并开启License共享。 AC 1（主，已安装正式 License）配置： # 配置 AP 组的备份 AC 地址（指向 AC 2） wlan ap-group 你的AP组名(默认default-group) backup-ac ip AC2的IP地址 wlan tunnel-preempt enable # 可选，主AC恢复后允许抢占 quit # 配置 AP License 共享组 wlan ap-license-group local ip AC1的IP地址 member ip AC2的IP地址 backup # 指定 AC2 为备角色 ap-license-synchronization enable quit AC 2（备，无正式 License）配置： # 配置 AP 组的备份 AC 地址（指向 AC 1） wlan ap-group 你的AP组名(默认default-group) backup-ac ip AC1的IP地址 quit # 配置 AP License 共享组 wlan ap-license-group local ip AC2的IP地址 backup # 声明自身为备角色 member ip AC1的IP地址 # 主 AC 为成员 ap-license-synchronization enable quit AP上线后，会同时与两台AC建立主/备隧道。 配置完成后，可以用 display wlan ap-license-group 命令查看共享组状态，确认两台 AC 已建立连接且授权信息同步成功
