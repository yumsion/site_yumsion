温度传感器 cat /sys/class/hwmon/hwmon0/temp1_input #温度传感器数值 查看每个目录下的 name 文件获取该传感器使用的内核驱动名称 for i in /sys/class/hwmon/hwmon*; do echo -n "$i: "; cat $i/name; done 驱动名称 (name) 通常对应的硬件 说明 coretemp Intel CPU 这是监控 Intel CPU 核心温度最关键的传感器。 k10temp 或 zenpower AMD CPU 监控 AMD CPU 温度。 nvme NVMe 固态硬盘 对应你的 NVMe 硬盘温度。 drivetemp SATA/SAS 硬盘 用于读取 SATA 硬盘温度（需手动加载模块）。 nct6775 / it87 / w83627ehf 主板 通常用于监控主板温度、风扇转速和电压。 bnxt_en Broadcom 网卡 mlx5 Mellanox 网卡 pch_lewisburg Intel PCH（南桥/芯片组） 主板芯片组温度，可作参考 temp*_input 的单位是毫摄氏度（m°C），例如 45000 表示 45°C。 你也可以安装 lm-sensors 软件包，运行 sensors 命令。它会以更友好的格式汇总所有传感器读数，并自动应用配置文件中的标签，让你一眼看出哪个是 CPU 温度、哪个是硬盘温度，方便交叉验证。
