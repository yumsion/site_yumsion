Xvnc 多屏
Xvnc创建多屏并运行程序【gemini版】 来自谷歌gemini的可用共享方案
要启动一个基于 XFCE4 的独立 VNC 桌面会话并绑定到 :1 显示端口（对应 TCP 端口 5901），可以通过配置 ~/.vnc/xstartup 并使用 vncserver / Xvnc 启动。
1. 配置 VNC 启动脚本
mkdir -p ~/.vnc

cat << 'EOF' > ~/.vnc/xstartup
#!/bin/sh
unset SESSION_MANAGER
unset DBUS_SESSION_BUS_ADDRESS

# 加载基础资源与键位映射（若存在）
[ -r $HOME/.Xresources ] && xrdb $HOME/.Xresources
[ -r $HOME/.xmodmap ] && xmodmap $HOME/.xmodmap

# 启动 D-Bus 会话与 XFCE4
if which dbus-launch >/dev/null 2>&1; then
exec dbus-launch --exit-with-session startxfce4
else
exec startxfce4
fi
EOF

chmod +x ~/.vnc/xstartup
2. 初始化 VNC 密码（首次使用）
vncpasswd
3. 启动 :1 会话
方式 A：使用 vncserver 包装脚本（推荐，TigerVNC / TightVNC 通用）
# 启动 :1 桌面，分辨率 1920x1080，24位色彩深度
vncserver :1 -geometry 1920x1080 -depth 24
方式 B：直接调用底层的 Xvnc 命令
# 1. 启动底层 Xvnc 服务
Xvnc :1 -geometry 1920x1080 -depth 24 -rfbauth ~/.vnc/passwd -rfbport 5901 &

# 2. 为该 DISPLAY 启动 XFCE4 会话
DISPLAY=:1 ~/.vnc/xstartup &

或手动启动

# 1. 启动 Xvnc X-Server（如未设置过密码请先执行 vncpasswd）
Xvnc :1 -geometry 1920x1080 -depth 24 -rfbauth ~/.vnc/passwd -rfbport 5901 &
#步骤 2：在新环境中清理变量并启动 XFCE
#在同一终端或新建会话中，显式指定 DISPLAY=:1 并清理会话变量：
env -i HOME="$HOME" USER="$USER" PATH="$PATH" DISPLAY=:1 dbus-launch --exit-with-session xfce4-session &
#参数说明：
#env -i：清空当前终端继承的 :0 环境变量。
#DISPLAY=:1：指定桌面渲染到刚才启动的 VNC 实例。
#xfce4-session：直接调用 XFCE 会话管理器（比 startxfce4 脚本更干净，避免其内部检测 :0 的逻辑干扰）。
