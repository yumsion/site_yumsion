curl ftp 用 curl 模拟 FTP 上传 curl -T 本地文件路径 ftp://用户名:密码@服务器地址/远程路径 指定远程文件名上传 curl -T localfile.txt ftp://user:pass@ftp.example.com/dir/remote-name.txt 沿用本地文件名上传 curl -T localfile.txt ftp://user:pass@ftp.example.com/dir/path/ 追加内容而非覆盖 curl -T localfile.txt --append ftp://user:pass@ftp.example.com/dir/existing-file.txt 批量上传 curl -T '*.jpg' ftp://user:pass@ftp.example.com/upload/ 被动模式：如果连接后卡住或报错，可以加上 --ftp-pasv 强制使用被动模式，这在很多网络环境下是必要的。 安全提醒：直接在命令行 URL 中写明文密码（user:pass）会被记录在 shell 历史中。更安全的做法是使用 -u user:pass 参数，或者交互式输入密码。 协议区分：上述命令针对的是传统 FTP 协议。如果你连接的是 SFTP（基于 SSH），URL 需改为 sftp:// 开头，用法类似。
