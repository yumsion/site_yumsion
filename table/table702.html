使用auditd记录whoami和id的命令的执行 systemctl status auditd 添加监控规则（监控 /usr/bin/id 和 /usr/bin/whoami 的执行）： 临时添加: # 监控 64 位架构下的 whoami 执行 auditctl -a always,exit -F arch=b64 -F path=/usr/bin/whoami -F perm=x -k reconnaissance_whoami # 监控 32 位架构下的 whoami 执行（建议补充，防止 32 位程序绕过） auditctl -a always,exit -F arch=b32 -F path=/usr/bin/whoami -F perm=x -k reconnaissance_whoami auditctl -a always,exit -F arch=b64 -F path=/usr/bin/id -F perm=x -k reconnaissance_id auditctl -a always,exit -F arch=b32 -F path=/usr/bin/id -F perm=x -k reconnaissance_id 写入配置文件（永久生效）： vim /etc/audit/rules.d/audit.rules -a always,exit -F arch=b64 -F path=/usr/bin/whoami -F perm=x -k reconnaissance_whoami -a always,exit -F arch=b32 -F path=/usr/bin/whoami -F perm=x -k reconnaissance_whoami -a always,exit -F arch=b64 -F path=/usr/bin/id -F perm=x -k reconnaissance_id -a always,exit -F arch=b32 -F path=/usr/bin/id -F perm=x -k reconnaissance_id 更新后执行以下命令重新加载配置并验证： augenrules --load auditctl -l 使用 ausearch + 管道（最简单的命令行实时查看） # 实时跟踪带有指定 key 的告警日志 tail -f /var/log/audit/audit.log | ausearch -k reconnaissance_whoami --raw
